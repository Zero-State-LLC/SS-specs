## Method

1. On runtime `922fc08` (ruleset-008), the four canonical end states were dumped with `StateDigest.canonical(...).serialize()`:
   - the three complete-run vectors (`testing_completeRunSuccess`, seed 1);
   - the smoke replay (`replay-smoke-001` through `Simulation.run`).

   All four hashed to the stored ruleset-008 digests.
2. In each dump exactly one field was replaced, `"rulesetVersion":"ss-rules-008"` → `"ss-rules-009"`, and the result was hashed with SHA-256. Those hashes are the new expectations below. No failing test output was copied to produce them.
3. The ruleset-009 runtime must reproduce them by actual execution, in the full suite.
