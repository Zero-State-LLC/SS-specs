# Visual production language

Shared terms for the character, device and environment review process.

## Language

**Grounded dynamic motion**:
Clear weight transfer with subtle differences between release phases, while retaining the character's restrained movement character.
_Avoid_: Extra bounce, faster-looking jog

**First sample**:
An initial visual proposal that establishes a family's appearance or role before detailed expansion. It is not an accepted family.
_Avoid_: Finished family, approved asset

**Visual acceptance**:
The owner's explicit approval of the appearance and motion presented for review. Technical verification and silence are not visual acceptance.
_Avoid_: Tests passed, implicitly approved
